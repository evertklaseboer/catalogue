Forged Fournier Cancel


Forged Fournier cancel as it can be found in 'The Fournier Album of Philatelic Forgeries' (reduced size): 'ADMINISTRATION DE CORREOS * NICARAGUA * 18 JUL. 18' (the year was probably to be added later). I don't know on which stamps this forged cancel was applied. If anyone has more information, please contact me!
