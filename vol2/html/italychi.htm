"PECHINO"

1918 Stamps of Italy overprinted "PECHINO" and surcharged with value

  2 c on 5 c green
  4 c on 10 c red
  4 c on 10 c red (other stamp of Italy)
  6 c on 15 c black
  8 c on 20 c on 15 c black
  8 c on 20 c orange
  20 c on 50 c violet
  40 c on 1 L brown and green

Many of these stamps exist with inverted or even double (one inverted and one in the right position). Misprints (8 c on 15 c, 40 c on 50 c) exist.

Value of the stamps

 
vc = very common
c  = common
*  = not so common
** = uncommon
 
*** = very uncommon
R   = rare
RR  = very rare
RRR = extremely rare
