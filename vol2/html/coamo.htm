(Genuine stamp)

A provisional stamp with inscription "CORREOS 5 CTS. COAMA" was issued in 1898 in Porto Rico in the color black. There are four types of this stamp (10 subtypes; as much stamps as there are in one sheet). Most (all?) stamps have a violet handstamped control mark "F.Santiago".

Value of the stamps

 
vc = very common
c  = common
*  = not so common
** = uncommon
 
*** = very uncommon
R   = rare
RR  = very rare
RRR = extremely rare
Value Unused Used Remarks
